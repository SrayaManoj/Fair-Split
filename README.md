🤝 Fair Split – AI-Based Project Task Allocator

Fair Split is a smart team management tool that uses the Hungarian Optimization Algorithm to fairly distribute project tasks among team members based on their skill ratings. It helps ensure balanced workload distribution and optimal task allocation in group projects.

🚀 Features

🧠 Optimization Intelligence: Uses the Hungarian Algorithm to assign tasks efficiently.

✍️ Interactive Skill Entry: Add students, tasks, and skill ratings directly in an editable grid.

⚖️ Fair Work Distribution: Ensures that each student gets the task they are most skilled at.

📊 Dynamic UI: Built with Streamlit for an interactive and easy-to-use web interface.

💡 Future AI Expansion: Can integrate ML models to predict skills or suggest team structures automatically.
